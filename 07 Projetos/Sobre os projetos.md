# Sobre os projetos

Portfólio de projetos do laboratório, seguindo o pipeline visto no [[Gestão da Inovação (WeGov)]]:

demanda → triagem → priorizado → protótipo → piloto → implantação → concluído (ou encerrado)

## Como registrar um projeto
1. Crie uma nota nesta pasta com o nome do projeto.
2. Rode **Inserir modelo** (`Ctrl+P`) e escolha **Modelo - Projeto**.
3. Atualize a propriedade `etapa` conforme o projeto avança. A tabela na [[Início|página inicial]] agrupa os projetos por etapa.

## Boas práticas
- Defina um **critério de saída** desde o início: quando parar se não houver evidências.
- Registre os **aprendizados** mesmo nos projetos encerrados.
- Se o projeto envolve IA, cadastre o sistema no `06 Inventário de IA` e ligue as duas notas pela propriedade `sistema_ia`.
